# Problem 2 submission pack

This folder contains the proposed solution and evidence for the Kuku Consumer Dispute Intake Assistant.

- `solution.pdf` is the two-page solution document.
- `solution.md` is the editable text source.
- `test_cases.json` contains three independent consumer-dispute intake prompts.
- `raw_outputs/` contains unedited terminal transcripts from running the three prompts through `agent.py` with the local Chroma index and Groq.
- `form_fields.md` lists the personal fields and links to enter in the assignment form.

The raw answers are model-generated and have not been legally validated. One answer extrapolates a limitation period from unrelated railway material; this is a known failure in the run. Review the transcripts and explain this limitation during evaluation. No walkthrough video has been recorded. A video is optional and should use the applicant's own voice.
