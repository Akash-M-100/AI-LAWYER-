# Problem 2 submission pack

This folder contains the proposed solution and evidence for the Kuku Legal Intake Assistant.

- `solution.pdf` is the two-page solution document.
- `solution.md` is the editable text source.
- `test_cases.json` contains three independent, user-authored rental/eviction intake prompts.
- `raw_outputs/` contains the exact reported Groq 403 error. Successful per-case outputs still need to be captured by running `run_test_cases.ps1` after Python, the local knowledge base, and Groq connectivity are available.
- `form_fields.md` lists the personal fields and links to enter in the assignment form.

No walkthrough video has been recorded. A video is optional and should use the applicant's own voice.
